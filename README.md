# browser_api_test
企业级POM分层接口自动化测试框架，专门针对移动端手机浏览器全业务接口自动化回归
覆盖登录、网页收藏、浏览历史、缓存清理、无痕模式五大核心模块，适配浏览器APP日常版本迭代回归。

## 技术栈
Python3.9+
1. requests：http接口请求，session会话保持
2. pytest：用例管理、参数化、全局夹具、代码覆盖率
3. PyYAML：用例、环境配置数据驱动，代码与用例解耦
4. loguru：分层持久化日志，方便报错排查
5. allure-pytest：可视化报告，自动挂载完整请求响应详情
6. python-dotenv：本地.env隔离账号密钥，杜绝代码泄密
7. jsonpath：返回json字段提取

## 分层架构（标准企业POM分层）
1. utils 工具层：全局路径管理、通用断言封装
2. config 配置层：多环境域名配置、全局变量统一管理
3. common 底层基础层：请求封装、日志、yaml读写、allure附件、json工具
4. page POM业务层：按业务模块拆分接口类，只封装接口调用，无断言
5. data 数据层：YAML存放所有测试用例，支持非开发人员改参数
6. testcases 用例层：pytest执行、参数化、allure分类、业务断言
7. reports/logs：自动生成报告、运行日志

## 覆盖全部浏览器业务模块
1. 登录模块：正常登录、密码错误、空账号异常校验
2. 收藏夹模块：新增收藏、查询收藏列表、删除收藏
3. 浏览历史：新增访问记录、一键清空全部历史
4. 缓存&无痕：清理全量/图片缓存、无痕模式开关控制

## 安全设计（适配企业开源规范）
1. 所有线上域名使用xxx脱敏占位，无内网真实地址
2. 账号、密码、签名密钥存本地.env，.gitignore屏蔽不上传仓库
3. 日志、报告、编译缓存全部不会提交到远程仓库

## 本地运行步骤
1. 安装依赖：pip install -r requirements.txt
2. 本地新建.env文件，填入自己真实测试账号密钥
3. config/env.yaml修改current_env切换测试/预发/生产环境
4. 一键运行：python run_all.py
5. 打开 reports/allure_html/index.html 查看可视化报告

## CI拓展
支持接入Jenkins配置定时任务，夜间自动全量回归浏览器接口，提前拦截后端参数、权限、逻辑bug。
